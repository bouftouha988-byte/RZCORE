Transparency

Exactly what RzCore.exe does

The player sees this list before anything starts. Nothing runs without their approval.

01

Running processes

Programs active on the PC at the moment of the scan.

02

Recent & Prefetch

Recently opened items and executables Windows has recorded.

03

Files and cheat signatures

File names on every drive, plus a local check of programs in user folders for cheat strings. Renamed cheats are still found.

04

Recycle Bin

Items that were recently deleted and are still recoverable.

05

Deletion history

Traces left behind by files that were removed.

06

PC timeline

When Windows was installed, when the PC started and which programs were uninstalled.

07

Browser history

Chrome, Edge, Brave, Opera and Firefox, matched against cheat names like Keyser, Susano, RedEngine or Vanity.

08

DNS and browser memory

Recently visited cheat sites, even if the browser history was cleared.

09

Execution traces

Programs that ran on the PC, including ones deleted afterwards.

10

Windows event logs

Cleared logs, drivers installed from user folders, Defender alerts and Defender being turned off.

11

Security settings

Defender exclusions, test-signing mode, vulnerable drivers and the deletion journal.

12

Security blockers

Tools built to disable Defender or hide traces, even if the file was deleted afterwards.

RzCore scans only run with the player's consent. When the scan ends, the report goes straight to your dashboard, and only the suspicious matches are included. File contents and the full browser history are never uploaded.
